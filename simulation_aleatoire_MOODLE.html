§ 01

Introduction — pourquoi simuler ?

La simulation numérique d'expériences aléatoires permet de vérifier empiriquement les résultats théoriques des probabilités et de traiter des modèles trop complexes pour une approche analytique directe.

🎯 Objectifs pédagogiques

  • Maîtriser le générateur pseudo-aléatoire Python
  • Simuler et estimer des probabilités numériquement
  • Vérifier la formule des probabilités totales
  • Vérifier la formule de Bayes
  • Simuler des lois usuelles (Binomiale, Géométrique…)

📐 Prérequis

  • Univers fini, probabilité d'un événement
  • Probabilité conditionnelle P(A|B)
  • Indépendance d'événements
  • Espérance d'une variable aléatoire
  • Bases Python (boucles, fonctions, listes)
Loi des grands nombres (intuition)
Quand le nombre n d'expériences tend vers l'infini, la fréquence empirique d'un événement A tend vers sa probabilité théorique P(A).
§ 02

Le module random de Python

Définition — Générateur pseudo-aléatoire

Un générateur pseudo-aléatoire (PRNG) est un algorithme déterministe produisant une suite de nombres qui apparaît aléatoire. À partir d'une graine (seed) donnée, la suite est toujours identique — garantissant la reproductibilité des expériences.

Fonctions essentielles du module random

FonctionDescriptionExemple de résultat
random.random()Réel uniforme dans [0, 1[0.7318…
random.uniform(a, b)Réel uniforme dans [a, b]3.14…
random.randint(a, b)Entier uniforme dans [a, b]4
random.choice(lst)Élément aléatoire d'une liste'pile'
random.shuffle(lst)Mélange une liste en place—

PYTHON · random_demo.py
import random

# Fixer la graine pour la reproductibilité
random.seed(42)

# Simulation d'un lancer de pièce
def lancer_piece():
    return random.choice(['Pile', 'Face'])

# Simulation de n lancers
n = 10000
resultats = [lancer_piece() for _ in range(n)]
freq_pile = resultats.count('Pile') / n

print(f"Fréquence de Pile : {freq_pile:.4f}")
print(f"Probabilité théorique : 0.5000")
Sortie
Fréquence de Pile : 0.5034
Probabilité théorique : 0.5000
⚠️ Rôle crucial de seed() : Sans seed fixée, chaque exécution donne des résultats différents. Avec random.seed(42), la suite de nombres est identique à chaque run — indispensable pour comparer des résultats ou déboguer.

§ 04

Simulation et calcul numérique de probabilité

Méthode générale

Pour estimer P(A) par simulation : répéter l'expérience n fois et compter le nombre k de réalisations de A. Alors P(A) ≈ k/n. Par la loi des grands nombres, cette approximation est d'autant meilleure que n est grand.

Méthode de Monte-Carlo — estimation de π

On tire uniformément des points dans le carré [−1,1]² et on compte ceux qui tombent dans le disque unité. Puisque l'aire du disque vaut π et l'aire du carré vaut 4, on a π ≈ 4 × (nombre de points dans le disque) / n.

PYTHON · monte_carlo_pi.py
import numpy as np

def estimer_pi(n):
    np.random.seed(0)
    x = np.random.uniform(-1, 1, n)
    y = np.random.uniform(-1, 1, n)
    dans_cercle = (x**2 + y**2) <= 1
    return 4 * np.sum(dans_cercle) / n

for n in [100, 1_000, 10_000, 1_000_000]:
    pi_hat = estimer_pi(n)
    print(f"n={n:>10,}  π̂ = {pi_hat:.5f}  erreur = {abs(pi_hat-3.14159):.5f}")
Sortie
n=       100  π̂ = 3.04000  erreur = 0.10159
n=     1,000  π̂ = 3.13200  erreur = 0.00959
n=   10,000  π̂ = 3.14360  erreur = 0.00201
n= 1,000,000  π̂ = 3.14202  erreur = 0.00043

§ 05

Probabilité conditionnelle — Simulation

Définition — Probabilité conditionnelle
P(A|B) = P(A ∩ B) / P(B),   si P(B) > 0

Pour simuler P(A|B) numériquement, on génère l'expérience de base et on filtre les cas favorables à B, puis on compte parmi ceux-ci combien réalisent A.

PYTHON · proba_conditionnelle.py
import numpy as np
np.random.seed(7)

# Dé à 6 faces
# A = obtenir un 6,  B = obtenir un chiffre pair
# Théorie : P(A|B) = (1/6) / (1/2) = 1/3

n = 200_000
des = np.random.randint(1, 7, n)

A = (des == 6)
B = (des % 2 == 0)

P_B             = np.mean(B)
P_A_et_B        = np.mean(A & B)
P_A_sachant_B   = P_A_et_B / P_B

print(f"P(B)   = {P_B:.4f}   (théorie = 0.5000)")
print(f"P(A∩B) = {P_A_et_B:.4f}   (théorie = 0.1667)")
print(f"P(A|B) = {P_A_sachant_B:.4f}   (théorie = 0.3333)")
Sortie
P(B)   = 0.4999   (théorie = 0.5000)
P(A∩B) = 0.1668   (théorie = 0.1667)
P(A|B) = 0.3337   (théorie = 0.3333)
§ 06

Formules des probabilités totales et de Bayes

Formule des probabilités totales
Si (B₁, …, Bₙ) est un système complet d'événements :
P(A) = Σᵢ P(A|Bᵢ) · P(Bᵢ)
Formule de Bayes
P(Bᵢ|A) = P(A|Bᵢ) · P(Bᵢ) / P(A)

Exemple : test médical (classique SUP)

Une maladie touche 1 % de la population. Un test a une sensibilité de 95 % et une spécificité de 90 %. Quelle est la probabilité d'être malade sachant que le test est positif ?

PYTHON · bayes_medical.py
import numpy as np
np.random.seed(42)

p_malade    = 0.01   # P(M)
sensibilite = 0.95   # P(T+|M)
specificite = 0.90   # P(T-|M̄)
n = 1_000_000

malade = np.random.random(n) < p_malade
u      = np.random.random(n)

test_pos = np.where(
    malade,
    u < sensibilite,
    u < (1 - specificite)
)

P_Tplus          = np.mean(test_pos)
P_M_et_Tplus     = np.mean(malade & test_pos)
P_M_sachant_Tplus = P_M_et_Tplus / P_Tplus

# Calcul théorique
num   = sensibilite * p_malade
denom = num + (1 - specificite) * (1 - p_malade)
P_theo = num / denom

print(f"P(M|T+) simulé  = {P_M_sachant_Tplus:.4f}")
print(f"P(M|T+) théorie = {P_theo:.4f}")
Sortie
P(M|T+) simulé  = 0.0875
P(M|T+) théorie = 0.0874
💡 Paradoxe de Bayes : Même avec un test très fiable (95 % de sensibilité), si la maladie est rare (1 %), la probabilité d'être réellement malade après un test positif est seulement d'environ 8,7 %. Ce résultat contre-intuitif est fondamental en médecine et en intelligence artificielle.
§ 07

Simulation des lois usuelles

1. Loi de Bernoulli B(p)

Définition

X ~ B(p) : X = 1 avec probabilité p, X = 0 avec probabilité 1−p. E(X) = p, Var(X) = p(1−p).

PYTHON · bernoulli.py
import numpy as np

def bernoulli(p, n):
    u = np.random.random(n)
    return (u < p).astype(int)

p, n = 0.3, 100_000
x = bernoulli(p, n)
print(f"E(X) = {np.mean(x):.4f}  (théorie = {p})")
print(f"Var  = {np.var(x):.4f}  (théorie = {p*(1-p):.4f})")

2. Loi Binomiale B(n, p)

Définition

X ~ B(n, p) : nombre de succès en n épreuves de Bernoulli indépendantes. E(X) = np, Var(X) = np(1−p).

PYTHON · binomiale.py
import numpy as np
from math import comb

np.random.seed(10)
n_b, p = 20, 0.4
X = np.random.binomial(n_b, p, 100_000)

print(f"E(X) simulé   = {np.mean(X):.4f}  (théorie = {n_b*p})")
print(f"Var(X) simulé = {np.var(X):.4f}  (théorie = {n_b*p*(1-p):.4f})")

k = 8
p_sim  = np.mean(X == k)
p_theo = comb(n_b, k) * p**k * (1-p)**(n_b-k)
print(f"P(X=8) simulé   = {p_sim:.4f}")
print(f"P(X=8) théorique = {p_theo:.4f}")
Sortie
E(X) simulé   = 7.9998  (théorie = 8.0)
Var(X) simulé = 4.7968  (théorie = 4.8000)
P(X=8) simulé   = 0.1147
P(X=8) théorique = 0.1144

3. Loi Géométrique G(p)

Définition

X ~ G(p) : rang du premier succès. P(X = k) = (1−p)^(k−1) · p pour k ≥ 1. E(X) = 1/p.

PYTHON · geometrique.py
import numpy as np

np.random.seed(5)
p = 0.25
X = np.random.geometric(p, 200_000)

print(f"E(X) = {np.mean(X):.4f}  (théorie = {1/p:.4f})")
print(f"P(X=1) = {np.mean(X==1):.4f}  (théorie = {p:.4f})")
print(f"P(X≥5) = {np.mean(X>=5):.4f}  (théorie = {(1-p)**4:.4f})")
Sortie
E(X) = 4.0038  (théorie = 4.0000)
P(X=1) = 0.2501  (théorie = 0.2500)
P(X≥5) = 0.3162  (théorie = 0.3164)

Simulation du paradoxe des anniversaires

★☆☆ Facile

Dans un groupe de n personnes choisies au hasard, on cherche la probabilité qu'au moins deux aient le même anniversaire (on suppose 365 jours équiprobables).

  1. Calculer théoriquement P(au moins une collision) pour n = 23.
  2. Écrire une fonction collision(n, N) simulant N groupes de n personnes et renvoyant la fréquence de collision.
  3. Pour n allant de 1 à 60, à partir de quel n la probabilité dépasse-t-elle 0,5 ?
Voir la solution
1. Calcul théorique (n = 23) : P(tous différents) = ∏ₖ₌₀²² (365−k)/365 ≈ 0.4927 P(collision) = 1 − 0.4927 ≈ 0.5073 2. Code Python :
PYTHON
import numpy as np

def collision(n, N=10_000):
    np.random.seed(42)
    groupes = np.random.randint(0, 365, (N, n))
    col = [len(set(g)) < n for g in groupes]
    return np.mean(col)

# Premier n pour lequel P > 0.5
for n in range(1, 61):
    if collision(n) > 0.5:
        print(f"Premier n : {n}"); break
Réponse : À partir de n = 23, la probabilité dépasse 0,5 — résultat surprenant illustrant l'importance de la simulation !

Vérification numérique de la formule de Bayes

★★☆ Moyen

Une usine possède 3 machines. M₁ produit 50 % des pièces (taux défauts 2 %), M₂ produit 30 % (3 %), M₃ produit 20 % (5 %).

  1. Calculer théoriquement P(D), la probabilité qu'une pièce soit défectueuse.
  2. Calculer P(M₁|D), P(M₂|D), P(M₃|D) par la formule de Bayes.
  3. Vérifier par simulation Python avec n = 500 000 pièces.
  4. Comparer résultats simulés et théoriques dans un tableau.
Voir la solution
1. Probabilités totales : P(D) = 0.02×0.5 + 0.03×0.3 + 0.05×0.2 = 0.010 + 0.009 + 0.010 = 0.029 2. Formule de Bayes : P(M₁|D) = (0.02 × 0.5) / 0.029 ≈ 0.3448 P(M₂|D) = (0.03 × 0.3) / 0.029 ≈ 0.3103 P(M₃|D) = (0.05 × 0.2) / 0.029 ≈ 0.3448 3. Code :
PYTHON
import numpy as np
np.random.seed(42)
n = 500_000
u = np.random.random(n)
machine = np.where(u < 0.5, 1, np.where(u < 0.8, 2, 3))
v = np.random.random(n)
taux = np.where(machine==1, 0.02, np.where(machine==2, 0.03, 0.05))
defect = v < taux
for i in [1, 2, 3]:
    p = np.mean((machine==i) & defect) / np.mean(defect)
    print(f"P(M{i}|D) = {p:.4f}")

Estimation de l'espérance — convergence en 1/√n

★★☆ Moyen

Soit X ~ B(15, 0.6).

  1. Calculer théoriquement E(X) et Var(X).
  2. Simuler N = 50 000 réalisations et estimer E(X), Var(X) empiriquement.
  3. Pour n = 10, 50, 100, 500, 1 000, 5 000 — montrer que l'erreur d'estimation diminue en O(1/√n).
Voir la solution
1. Valeurs théoriques : E(X) = 15 × 0.6 = 9 Var(X) = 15 × 0.6 × 0.4 = 3.6
PYTHON
import numpy as np
np.random.seed(99)
X = np.random.binomial(15, 0.6, 50_000)
print(f"E(X)   = {np.mean(X):.4f}")
print(f"Var(X) = {np.var(X):.4f}")

for n in [10, 50, 100, 500, 1000, 5000]:
    err = abs(np.mean(X[:n]) - 9)
    print(f"n={n:5d}  erreur={err:.4f}  1/√n={1/n**0.5:.4f}")
Conclusion : La convergence en 1/√n est le fondement de toute estimation statistique (Loi des Grands Nombres).

Problème de la ruine du joueur (Gambler's Ruin)

★★★ Difficile

Un joueur commence avec un capital de k €. À chaque étape il gagne 1 € avec probabilité p ou en perd 1 avec probabilité 1−p. Il s'arrête à N € (victoire) ou 0 € (ruine).

  1. Écrire une fonction Python simulant une partie, renvoyant True si le joueur est ruiné.
  2. Estimer P(ruine | k=5, N=10, p=0.5) sur 100 000 parties.
  3. Comparer avec la valeur théorique P_ruine = (N−k)/N si p = 0.5.
  4. Étudier l'impact de p ∈ {0.4, 0.45, 0.5, 0.55, 0.6}.
Voir la solution
PYTHON
import numpy as np
np.random.seed(77)

def partie(k, N, p):
    while 0 < k < N:
        k += 1 if np.random.random() < p else -1
    return k == 0

def p_ruine(k, N, p, n=20_000):
    return sum(partie(k, N, p) for _ in range(n)) / n

k, N = 5, 10
for p in [0.4, 0.45, 0.5, 0.55, 0.6]:
    sim = p_ruine(k, N, p)
    q   = (1-p)/p
    theo = (N-k)/N if p == 0.5 else (q**k - q**N)/(1 - q**N)
    print(f"p={p}  simulé={sim:.4f}  théorie={theo:.4f}")
Interprétation : P(ruine | k=5, N=10, p=0.5) = (10−5)/10 = 0.5 Même un très léger avantage de la maison (p = 0.45 pour le joueur) augmente massivement la probabilité de ruine — fondement mathématique de l'industrie du jeu.
